# 余音 · 鸿蒙端 代码混淆规则
#
# 官方说明:https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/source-obfuscation-V5
#
# ── 为什么只开这几项(不是照抄 SDK 模板) ─────────────────────────────
# DevEco 模板默认把四项全开(property / toplevel / filename / export)。
# 本工程**刻意不开**其中三项,理由逐条如下 —— 要开也可以,但必须先在真机上把
# 下面列的场景全过一遍,不能只看编译通过。
#
# ✗ -enable-property-obfuscation(改属性名)风险最高:
#     · ArkUI 的 @Observed / @ObjectLink / @State 依赖**属性名**做变更追踪。
#       本工程刚把全部 store 改成 @ObjectLink 观察(见 TROUBLESHOOTING H26/H27),
#       属性名一改,最坏情况是"界面不刷新"这类静默失效 —— 正是最难在提交复核前发现的一类。
#     · 直接交给系统 API 的对象字面量必须保持原名:
#       systemShare.SharedData({ utd, uri, title })、avSession.setAVMetadata({ assetId, ... })、
#       notificationManager.publish({ content: { normal: { title, text } } })、
#       workScheduler.WorkInfo({ workId, bundleName, abilityName, ... })。
#     · Codec 的 JSON 键虽是字符串字面量(不受影响),但备份/偏好的**读写两端**
#       一旦有一侧被改名,表现是数据"看起来丢了",排查代价极大。
#
# ✗ -enable-filename-obfuscation(改文件名):路由与入口按路径引用 ——
#     module.json5 的 srcEntry、resources 下的 main_pages.json、
#     以及 loadContent('pages/Index')。改名后这些引用要靠工具链全部同步,
#     出错即启动白屏。
#
# ✗ -enable-export-obfuscation(改导出名):本工程单 HAP,收益有限;
#     而 EntryAbility / FeedUpdateExtension 由配置按名引用,风险大于收益。
#
# ✓ 已开启的两项:
#     -enable-toplevel-obfuscation 全局作用域内的名字(函数/类/变量)
#     -compact                     去掉多余空白与换行
#   这两项不改变任何"按名字找东西"的运行时行为,是首次发布的安全底线。
#
# ── namecache ─────────────────────────────────────────────────────
# ⚠️ 2026-10-10 更正这段口径(原先写"入库 + 后续版本用 -apply-namecache 复用同一份映射",
# 而**这个文件里根本没有 -apply-namecache** —— 那个词只出现在注释里,从未生效):
#   · 现在只有 -print-namecache,所以这份 json 是**每次 release 全量重编号的输出**
#     (加一点代码就漂 8,000+ 行),它不是任何一步的输入;
#   · 崩溃栈还原用的是 **harmony/dist/reverb-symbol.zip 里的 entry/entry-nameCache.json**
#     (实测与工作区这份逐字节相同),那才是每次发布的权威映射,且随包一起归档;
#   · 因此"跨版本混淆结果稳定 / 增量更新不因改名而全量替换"这两句**目前不成立**。
# 要真做得加一行 `-apply-namecache ./obfuscation-namecache.json`,而那会改变产物的符号名,
# 属于要重打 + 真机冒烟的改动,不在注释里顺手宣称。(留/撤这份入库副本同样待拍板。)

-enable-toplevel-obfuscation
-compact

-print-namecache ./obfuscation-namecache.json

# ── 保留名单 ──────────────────────────────────────────────────────
# 由 module.json5 / 系统按名字拉起的入口,一律不改名。
-keep-global-name
EntryAbility
FeedUpdateExtension
BackupExtension
