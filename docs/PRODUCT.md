# 余音 · Reverb 功能介绍

> 一款安静的多端播客客户端。**没有推荐流、没有广告、不需要注册、没有服务器。**
> 现有三个原生版本:**Android**(Kotlin / Compose)、**macOS**(Swift / SwiftUI)、
> **HarmonyOS**(ArkTS / ArkUI)。
>
> 这份文档是**面向使用者与评审的完整介绍**:每个功能是什么、怎么用、在哪一端什么样。
> 需要逐项对照的开发用矩阵见 `FEATURES.md`(那份是权威清单,本文档不重复它的表格细节);
> 实现原理见 `ARCHITECTURE.md`。
>
> **两个渠道**:自分发版(官网 / GitHub Releases)与**大陆商店版**功能范围不同,
> 原因是合规口径(见文末「渠道差异」一节与 `docs/HISTORY.md` 阶段五)。凡有差异之处本文都会点明。

---

## 一句话说清它是什么

**你自己攒起来的播客库,只存在你自己的设备上。**

没有服务器意味着:没有账号可注册、没有云端可同步、也没有任何人能看到你听了什么。
订阅、历史、收藏、下载、收听时长、印记全部保存在应用私有目录,卸载即删除。
应用联网只做三件事:拉发布方的 RSS、下载/播放发布方的音频与封面、
以及你主动点「导入推荐订阅」时从官网取一份订阅清单。

## 二、把节目找进来

### 粘贴 RSS 地址(所有版本)

搜索框里粘贴 `http(s)` 或 RSS 地址,直接解析导入。这是最本质的一条路——
只要发布方有 RSS,余音就能订阅,不依赖任何目录服务。

### 导入推荐订阅(所有版本)

还没有心爱的节目时,点一下「导入推荐订阅」,从官网取一份精选清单**整份导入**。
这是**大陆商店版的首屏入口**。

### 分类热门榜与关键词搜索(**仅自分发版**)

19 个分类的每日热门榜(推荐 / 新闻 / 商业 / 科技 / 文化 / 知识 / 教育 / 喜剧 / 健康 /
历史 / 体育 / 美食 / 旅行 / 动漫 / 情感 / 艺术 / 音乐 / 亲子 / 影视),
磁盘缓存秒开、后台刷新;以及「单集 + 节目」两个分段并行的关键词搜索。

- Android:分类 chips + 横滑分页,支持下拉刷新,分类顺序可长按拖拽自定义
- macOS:安静的分类下拉菜单 + 卡片网格,工具栏刷新按钮

**大陆商店版没有这一节的全部内容**,而且不是"藏起来"——安装包里连目录接口地址都没有。

### 新手引导音频(所有版本)

全新安装且没有任何使用痕迹时,发现页顶部有一张引导卡,点按播放随包内置的 30 秒音频。
它的用途是让你在**完全没有网络、还没订阅任何节目**时就能走通整条播放链路
(播放条 / 进度 / 倍速 / 后台 / 锁屏)。有任何使用痕迹后它就不再出现,且不计入历史与收听时长。

## 三、听

### 播放页

全屏播放页是横滑的多页结构:

1. **封面**——背后是会随播放流动的水墨声波
2. **节目笔记**(shownotes)
3. **逐字稿**——见下一节(有稿时才出现)

底部是进度条、快退/快进、上一集/下一集。频道名可点,跳到该频道主页
(听随机电台时尤其有用——你会想知道这是谁)。

### 播放能力

| 能力 | 说明 |
|---|---|
| 后台与锁屏 | 退出界面、锁屏后继续播;系统媒体控制可切集 |
| 倍速 | 0.8× / 1.0× / 1.25× / 1.5× / 1.75× / 2.0×,可设默认值 |
| 快退 / 快进 | 秒数可在设置里改 |
| 睡眠定时 | 15 / 30 / 45 / 60 分钟,或「听完本集」;最后 8 秒音量线性渐弱后暂停 |
| 音频淡入 | 每次开播新节目音量柔和渐入(约 0.9 秒),不炸耳 |
| 精准续播 | 记住每集进度,重进自动定位;回跳有护栏——不会把你甩回开头,也不会漏掉结尾 |
| 已播完标记 | 自然听完自动标记并把进度归零;也可手动切换 |
| 播放队列 | 「下一个播放」置顶 / 「加入队列」入队,可视化查看、重排、清空 |

### 水墨声波

播放时封面背后的墨纹会流动。**自分发的 Android 版**可以在设置里开「真实频谱」,
让墨纹跟随实际音量起伏——这需要麦克风权限,音频**只在本机做频谱计算,不录制、不保存、不外发**,
默认关闭。macOS 与鸿蒙没有等价的系统能力,走纯程序化墨纹。

## 四、逐字稿(跟读)

播放页横滑到第三页,这一集的文字逐句显示,**跟着播放进度高亮**,点一句就跳到那一刻。
每单集 × 每语言一份缓存,再进来秒开。

**文字从哪来,三端不同**——这是可用的系统能力与渠道口径决定的:

| | 发布方提供的逐字稿 | 本机转写 |
|---|---|---|
| **macOS** | 有 | 有(系统 `SpeechAnalyzer`,**词级时间**) |
| **Android 自分发版** | 有 | 有(内置 whisper.cpp,词级时间) |
| **Android 大陆商店版** | 有 | **无**(包里不含引擎与模型) |
| **HarmonyOS** | 有 | **无**(系统离线识别实测质量不够用) |

没有本机转写的版本里,**只有发布方给了逐字稿的单集才会出现第三页**——不给你一个点了没用的空页。

一个现实提醒:**中文播客基本没有官方逐字稿**(实测 15 个中文 feed,`podcast:transcript` 零命中);
英文播客有一些,尤其自动生成稿的托管商。所以对中文内容,真正管用的是自分发版的本机转写。

### 逐字高亮(设置项)

打开时**逐字点亮**而不是整句一起亮。它需要稿件自带**词级时间**:
JSON 格式的官方稿通常有,SRT / VTT 只有句级时间,那时自动退化成整句高亮。
自分发 Android 版的本机转写也有词级时间,**且不额外增加转写耗时**。

## 五、音阁(你的库)

五个分段:**订阅 / 最新 / 收藏 / 下载 / 历史**。

- **最新** 是跨全部订阅聚合的新单集:并发拉取、去重、按发布时间倒序,持久化后秒开再增量刷新。
  它不是一个独立入口,而是收纳在音阁里的一段。
- **下载** 的单集播放时优先用本地文件;可设「仅在 Wi-Fi 下载」(Android / 鸿蒙)。
- **历史** 支持一键清空;未播完的会出现在发现页的「继续收听」横条里。

频道详情页**离线优先**:先出上次解析结果(秒开,不从加载态起步),再后台刷新;
刷新失败沿用缓存并标注「离线内容 · 上次更新 …」。

## 六、让听过的留下痕迹

这一组是余音的性格所在——它们都不联网、不外发,只是帮你把「听」变成可回看的东西。

### 收听时长

按频道累计**你真正听过的内容时长**:反复听会累加,快进跳过与暂停不计入。
频道主页头部显示「已收听 X 小时 Y 分」,音阁里有一页按时长从多到少排序、带横条对比。

**多设备不会算错**:时长按设备分账存储,展示值是各设备之和,备份合并按设备取最大值。
所以——同一份备份重复恢复不会翻倍,换机恢复会把两台的时长正确汇总,
各设备自己新听的也不会被抹掉。

### 听觉印记与足迹

为一集盖一枚 **3×3 水墨情绪印章**(喜 / 暖 / 燃 / 惊 / 思 / 悟 / 悲 / 怒 / 疲),
再点同一枚即取消。所有印章汇成一张**听觉足迹**海报,可导出。

### 剪藏此刻

把当下这一句做成卡片(封面 + 标题 + 时间点 + 水墨波纹),系统分享或保存到相册。

## 八、数据是你的

- **完整备份与恢复**:订阅、下载记录、历史、设置、收听时长(可单独勾选分区),用于换机
- **OPML 导入导出**:标准格式,可与其它播客应用互通
- **清除**:缓存、下载、历史各自独立清除,都有二次确认

恢复备份的合并规则是**保守的**:历史按更新时间取新(旧备份不会让当前进度倒退),
收听时长按设备取最大值(不会重复累加)。

## 九、隐私

完整政策见 `PRIVACY.md` 与官网。要点:

- 不收集个人信息;没有服务器、不要求注册登录、**不接入任何第三方 SDK**、不埋点、不做用户画像、不展示广告
- 数据只存在本机,卸载即删除
- 联网只访问**发布方自己的**RSS / 音频 / 封面地址,以及你主动点「导入推荐订阅」时的官网清单;
  请求不携带任何鉴权凭据与用户标识
- **首次启动有隐私同意门**:同意之前,任何会联网或读系统网络信息的组件**一个都不装配**
- 本机转写(自分发 Android 版 / macOS)全程在设备上完成,**音频不上传、不出设备**

关于麦克风:只有**自分发 Android 版**的可选功能「真实频谱」会用到,默认关闭、
系统单独征求同意、音频只做本机频谱计算。**大陆商店版的安装包里没有麦克风权限**(可解包验证)。

## 渠道差异(为什么两个版本不一样)

大陆应用商店要求 APP登记,而合规口径把「内置内容目录 / 分类浏览 / 内容推荐」
判定为提供视听节目服务,需《相应内容分发许可资质》——个人主体拿不到;
「用户自行添加 RSS 源」的纯工具则不需要。

| | 自分发版 | 大陆商店版 |
|---|---|---|
| 分类热门榜 / 关键词搜索 / 电台 / 内置精选清单 | 有 | **无**(包里也没有) |
| 首屏 | 分类榜单 | 「导入推荐订阅」+ 粘贴 RSS |
| 本机语音转写 | 有(Android / macOS) | **无** |
| 真实频谱(麦克风) | 有(Android,可选) | **无** |
| 播放 / 订阅 / 最新 / 下载 / 收藏 / 历史 / 印记 / 收听时长 / 备份 / OPML | 有 | 有 |

**「界面上点不到」不等于「包里没有」**——被去掉的功能是编译期整体剔除的,
解包也找不到相关代码与接口地址。这一点是可验证的,不是承诺。

HarmonyOS 端**只经应用市场分发**,因此始终是商店版的功能范围。
macOS 走 dmg 自分发,不涉及商店,功能与自分发版一致。
