# 版本更新日志(对外)

> 面向用户的版本说明,**可以直接发给用户 / 贴到发布页**。
> 内部账本(验收读数、"没验过"这类措辞)在 `CHANGELOG.md`,不要从这里反向抄。

## 1.0.9 — 2026-11-22

### 新增

- **电台**:新增顶层「电台」页面(四端)。「我的电台」可以手动添加、编辑、删除直播电台(名称、流地址、可选台标与分组);「在线目录」按名称搜索全球电台,也有按地区的热门列表;还随包带了 16 条精选,点「+」就能加进自己的列表。点任意一条直接开播,播放页显示「直播中」,不给进度条与倍速。自己加的电台如果没有台标,会显示一枚默认的波形图标。
- **在线目录只列出能连上的电台**:搜索与热门结果会先逐个确认能否播放,连不上的不再显示(四端)。
- **投播**:把正在播放的声音交给同一个 Wi-Fi 下的其他设备 —— Android 投到支持 DLNA 的电视 / 盒子 / 电脑,鸿蒙用系统的投屏选择器,macOS 与 iOS 用 AirPlay(四端)。投播时本机先暂停,待播队列与进度原样保留;停止投放即回到本机接着听。

### 修复

- 在线目录在部分网络下会卡在「目录连不上」——调整了批量取数与等待时间,热门列表与搜索现在能正常返回。

### 说明

- 投播要求两台设备在同一个 Wi-Fi 下,且对方支持对应协议。手机、Mac 自带的「隔空播放 / 屏幕镜像」接收器不是 DLNA 设备,Android 端找不到它;反过来,AirPlay 也只认 Apple 设备。
- 在线目录来自 radio-browser.info;目录结果在展示前会向每个电台主机各发一次只取响应头的请求,对方因此能看到你的 IP 与应用的请求标识。检索与确认都不需要账号,不会上传收听记录。
- 隐私政策有更新(补充第三方目录与投播说明),本版会重新征求一次同意。
- 电台列表只进手动备份,不参与局域网同步。

## 1.0.8 — 2026-11-18

### 新增

- **章节**:发布方在节目里给出章节时,播放页进度条上方会显示当前章节名;点开是整张章表,点一条直接跳到那一段,正在播的那一章高亮。章表会存一份在本机,断网、飞行模式里也能看、能跳(四端)。
- **逐字稿搜索与导出**:逐字稿页可以按句子搜索并显示「第几处 / 共几处」,点箭头逐处跳转、同时把音频定位到那一句;也可以导出纯文本或 Markdown,通过系统分享发出去(四端)。
- **局域网同步**(Android / 鸿蒙 / macOS / iOS):同一 Wi-Fi 下,两台设备在「设置 → 局域网同步」里互相点一下、核对六位配对码,就能把订阅、收藏、印记、批注、播放历史与收听统计合并到一起;取消订阅、删除批注等删除也会同步到对端。数据只在这两台设备之间传输,不经过任何服务器,也没有账号;自动发现不了网络时可以手动填地址。
- **跨设备接着听**(Android / 鸿蒙 / macOS / iOS):局域网同步连上之后,正在播放的一台会把「在听哪一集、听到哪」告诉另一台;
另一台显示「另一台设备正在播放 …」并给出一个「在此设备继续」,点一下就从这个进度接着播,换房间、换设备不用找进度。
**不会自动接管**:必须你自己点;直播流不参与;关掉这个页面连接就断,不会在后台常驻。
- **本机语音识别升级**(Android / 鸿蒙):改用 SenseVoice 离线模型,中文识别更准,自带标点与逐字时间,全程在本机完成。支持中文、英文、日语、韩语、粤语;法语与西班牙语界面只显示发布方提供的官方稿。
- **桌面小组件 / 服务卡片可以控制播放**:上一集 / 播放暂停 / 下一集,进度约 5 秒刷新一次;按键只在后台改变播放状态,不拉起应用界面,应用没在运行时也能直接起播。Android 与鸿蒙都有四档尺寸;鸿蒙点卡片直接进播放页,按一次返回即退出应用。iOS 17 / macOS 14 起,系统小组件同样带播放控制(macOS 13 只显示封面与进度)。
- **锁屏与灵动岛**(iPhone):开始播放后,锁屏和灵动岛会显示正在播的节目、进度与 上一集 / 播放暂停 / 下一集;暂停时留在原地方便续播,一段时间没有继续就自动收起。进度由系统自己走,不会为此让应用常驻耗电。

### 修复

- Android 桌面小组件现在可以拉满整行宽度(原先最宽只能差一格到头)。
- Android 切换界面语言时偶发的整屏无响应已修好。
- 鸿蒙服务卡片:进度不再定住不动;上一集 / 下一集真正能切集;按播放键时封面不再重新加载闪一下。
- 鸿蒙服务卡片去掉了没有信息的「继续收听」小字,标题从顶部开始排。
- Android 播放条点 X 关闭时的粒子消散改成与鸿蒙一致的细碎粒子(原先碎块偏大、数量偏少)。

### 说明

- 局域网同步需要两台设备在同一个局域网内,首次配对要人眼核对配对码。跨网络同步、锁屏后台自动接力不在这一版范围内。
- 跨设备接着听只在两台设备都打开「局域网同步」页面时生效;接着播时播放方会先暂停,另一台从它暂停的位置补上网络往返的半程时间再起播。
- Android 17 起,首次打开「局域网同步」时系统会询问一次「本地网络」权限;拒绝后该功能不可用,可随时在系统设置里改。Android 16 及更早的系统没有这一步。
- 局域网同步的删除记录保留 90 天;播放历史与收听统计各设备各存一份,不参与删除同步。
- 逐字稿在本机生成,准确度受音频质量与语种影响;iOS 使用系统语音模型,需要较新的系统版本。
- 桌面小组件能拉多宽、多高由桌面的网格决定,不是所有桌面都能拉满。

## 1.0.7 — 2026-11-10

### 新增

- 双击当前所在的底部标签(发现 / 追更 / 音阁),列表立即回到顶部 —— 滑得很远时不用一路往回拖。
- 「追更」有新内容时自动回到顶部,不再停在上次看到的位置。
- 四端新增「继续收听」桌面小组件 / 服务卡片:封面、标题、频道名与进度直接摆在桌面上,有小 / 中 / 大三种尺寸,点一下就从上次的位置接着听(打开时是暂停的,不会自己出声)。
- 需要用户名和密码的私有 RSS 源也能订阅了:对方要求时输入一次账号密码,订阅、播放、下载与官方逐字稿都会带上;凭据只保存在本机,不进备份,退订该源时一并删除。
- 频道详情页的分享图改成 3:4 的朋友圈海报(封面 + 节目名 + 简介)。存进相册后,在微信朋友圈里选这张图即可发布;受微信限制,应用不能直接替你发朋友圈。
- 粘贴一路网络电台 / 直播流的地址,直接当播客听(四端)。播放页显示「直播中」,不给进度条与快进
  (直播没有"听到哪了"这回事),也不记录播放进度、不进历史、不占缓存空间。

### iOS(TestFlight)

- 新增「仅 Wi-Fi 下载」设置;下载、首次播放的缓存与转录前的整集音频都会先过这道判断,被拦下时会给出提示。
- 频道分享卡片、剪藏海报与足迹海报可以分享,也可以存进相册。
- 追更、收藏、下载、历史与频道页支持长按单集「多选」,勾选后一次加入待播;订阅列表可切换宫格。
- 订阅有新一期时会在后台检查并通知你;通知权限被拒时开关自动回到关闭。
- 外观新增四档字号。
- 修复:部分设置行与播放页小字在浅色主题下看起来像「禁用」;播放页下载按钮与其余按钮样式一致,并显示下载状态;删除离线文件前会确认,且不会因自动续播删错集;睡眠定时显示剩余时间;倍速菜单显示实际档位;换地区后榜单立即更新;迷你播放条新增频道入口、待播与关闭;冷启动后从暂停位置回到播放页时,总时长不再显示 0:00、进度条不再满格。
- 补全英文、法文、西班牙文与繁体中文的界面文案,系统权限弹窗的说明也一并本地化。

### 修复

- B 站搜索结果里不再夹杂与关键词无关的视频;标题明显不相干的条目会被挡掉。
- macOS 关掉主窗口后,再点 Dock 图标(或从 Finder 重新打开)窗口会回来了;最小化后点 Dock 也会恢复。

### 说明

- 直播流只支持你主动粘贴的那一条地址;节目与单集的搜索、目录、投播到其他设备都**不在**这一版里。
- 断流时播放会停下,不会自动换到别的内容。

## 1.0.6 — 2026-10-31

### 新增

- 支持粘贴 B 站链接或 BV 号,直接当播客播放(三端)
- 支持关键词搜索 B 站视频,结果与播客单集并列,点击即播放
- 播放条新增 X 关闭钮:停止播放并以粒子消散退场,待播队列保留
- 设置新增「检查更新」,并能识别「同版本号重新发布过安装包」(Android)
- macOS 也能在「设置 → 检查更新」里检查并下载新版
- 关于页「主要功能」补上电台
- macOS 补齐手机端功能:三格外壳、分类排序、批量加入待播、备份分区往返、自动缓存、发布方逐字稿

### 修复

- 点开 B 站视频只提示「这一集暂时播不了」——接口要求匿名标识,已按接口区分处理
- 充电专属视频出现在搜索结果、点开必然失败——不再展示
- 播不了的一集不再把播放条和播放页切走,原来那一集继续播
- 视频接口瞬时断连导致连续几条都播不了——自动补试一次
- 视频时长按整条视频显示——改为按正在播的那一段
- 崩溃可能丢数据——本地数据改为原子写入,坏数据只跳过一条
- 「仅在 Wi-Fi 下载」被转写前的下载绕过——统一拦截
- Android 播放出错后点不动——自动重试两次,并可手动重试
- 断网后「检查更新」永久卡在「正在检查…」
- macOS 设置页磁盘大小不刷新
- 备份往返会改动设置——不再改动
- macOS 日志记录搜索词——改为只记词数
- 一批小错:搜「AT&T」被截成「AT」、详情页切标签不生效、逐字稿串集、加载失败后进度归零、鸿蒙切语言回调泄漏
