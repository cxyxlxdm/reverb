# 余音 · Reverb 功能清单

> 一款轻量的多端播客客户端。**纯客户端、零开发者后端、零 API Key、不接广告、统计等数据上报 SDK,打开即用。**
> 现已提供 **Android**(Kotlin / Jetpack Compose)、**macOS**(Swift / SwiftUI)、**鸿蒙**(ArkTS / ArkUI,HarmonyOS NEXT)三个原生版本。
> 本文档按功能域汇总当前全部能力,供产品与开发对齐。凡各端行为不同或为单端独有,均在「平台差异/说明」注明。
>
> **鸿蒙端已具备**:取源与 RSS 解析、分类热门榜、节目 + 单集关键词搜索、RSS 导入、频道详情与订阅、
> 随机 / 情境电台、音阁五分段(订阅/最新/收藏/下载/历史)、播放页 + 后台播放 + 进度续播 + 系统媒体会话与锁屏控制、
> 下载离线、播放队列、收听时长(按设备分账)、听觉印记与足迹画廊、
> 剪藏此刻(存入相册)、设置(分区与条目已对齐 Android:内容 / 外观 / 播放 / 提醒 / 存储 / 备份 / 日志 / 关于)。
> 鸿蒙端还具备:**备份恢复 / OPML 导入导出、订阅更新提醒(周期检查 + 本地通知)、
> 仅 Wi-Fi 下载、清除缓存 / 清除下载 / 清空历史(均带二次确认)、分享日志(系统分享面板)/ 导出日志 / 清空日志、
> 关于与开源许可页、版本号**,界面文案完整外置(283 键 × 5 语言:简中 / 英 / 法 / 西 / 繁中)。
>
> 鸿蒙端的**图标体系**用系统 Symbol 字体(`SymbolGlyph`)与 Android 的 Material Rounded 逐个对应
> —— `sys.media.*` 仅 66 个图标、缺齿轮/柱状图/宫格/心形/月亮/下载等,不足以对齐。
> 鸿蒙端还具备:**逐字稿(读发布方在 RSS 里提供的稿,播放页第三页跟读高亮)**。
> 鸿蒙端**尚未包含**:真实频谱(鸿蒙无等价系统混音抓取,按 macOS 走纯程序化墨纹)、
> **本机语音转写** —— 该端的 native 解码链已就绪并真机验过,但系统的 Core Speech Kit 离线档
> 是给短语音输入设计的,实测质量不够用(见 `TROUBLESHOOTING.md` H62),故由
> `Features.LOCAL_ASR = false` 关着;要开需先换引擎,路径见 `TRANSCRIPT.md`。

## 渠道差异(重要)

同一份代码打两种包,**功能范围仍有差异**。起因是大陆分发合规口径:「内置内容目录 /
分类浏览 / 内容推荐」可能被判定为提供视听节目服务,需相应内容分发许可资质
(个人主体拿不到);而「用户自行添加 RSS 源」的纯工具不需要。此前据此移除了商店渠道的内容目录
(H67/H70)。当前决定是**首版先按完整版目录能力发行,若合规要求再降级**。

| | 默认渠道 | 大陆商店渠道 |
|---|---|---|
| 分发 | 官网 / GitHub Releases | 大陆应用市场;**目前实际只上过华为应用商店**(在架停在 1.0.1,1.0.2 审核被拒 ⇒ 暂停,见 H120)。鸿蒙端**只有商店这一种**,且 1.0.3 已在架 |
| 包名 | `com.yuyin.reverb.android`(1.0.1 起两渠道统一,包名只区分平台;鸿蒙 `com.yuyin.reverb`) | `com.yuyin.reverb.android` |
| 分类热门榜 + chips + 横滑分页 | 有 | **有** |
| 随机 / 情境电台 | 有 | **有** |
| 内置精选清单(144 条) | 有 | **无**(文件不在包里;首次内容只靠在线榜单) |
| 关键词检索(Apple/fyyd/gpodder) | 有 | **有**(节目 + 单集) |
| 搜索框 | 关键词 + RSS 地址 | 关键词 + RSS 地址 |
| 首屏 | 分类榜单 | 分类榜单 |
| 首启隐私同意门 | **有** | **有**(平台合规指引) |
| 真实频谱(麦克风) | 有(可选,默认关) | **无**(包里也没有 RECORD_AUDIO 权限) |
| 逐字稿(播放页第三页) | 有:发布方没给稿时用**内置的 whisper.cpp** 本机识别 | **只读发布方提供的稿**,没稿就不出第三页(Android 该渠道不含引擎;鸿蒙的系统识别实测质量不够用,见 TROUBLESHOOTING H62) |
| 播放 / 订阅管理 / 最新聚合 / 下载 / 收藏 / 历史 / 印记 / **批注** / 收听时长 / 备份 / OPML 导入导出 | 有 | 有 |

**注意隐私同意门不分渠道**:`MainActivity` 里是无条件门控(`if (accepted) … else PrivacyConsentScreen`),
两个渠道都会出。此前本表写成「默认渠道无」是错的 —— 而这条影响的不只是文档:
完整版也要看这一页,所以同意页正文必须把**完整版独有的麦克风权限**如实说明
(见 `privacy_consent_mic`,分渠道字符串,国内渠道为空)。

当前开关状态:Android `CATALOG`(`app/build.gradle` 的 flavor)与鸿蒙
`ets/Features.ets` 的 `CATALOG` 都开启;`SPECTRUM` / `LOCAL_ASR` 仍按渠道关闭。
若合规要求回退,只降级目录能力,不要连带改变频谱或转写。**鸿蒙没有 DCE**,
关闭布尔值仍会把两支都编进包;降级时必须把目录实现移出 `Sources.ets` 所在的编译树。
无论恢复还是移除,都要按 H70 解包 grep 验证,并同步本表。

macOS 走 dmg 自行分发,不涉及应用商店,功能与默认渠道一致。

## 信息架构(IA)

顶层只有两个入口:**发现** 与 **音阁**。「最新(收件箱)」不是独立入口,而是收纳在「音阁」内的一个分段。播放页、设置、听觉足迹为独立全屏/独立窗口。

| 平台 | 顶层导航形态 | 设置入口 |
|------|--------------|----------|
| Android | 底部导航为悬浮玻璃长椭圆(发现 / 音阁);发现页顶部为分类玻璃胶囊条;播放页、设置、频道详情为全屏页整体转场,底部常驻迷你播放条 | 音阁右上角齿轮 → 设置全屏页 |
| HarmonyOS | 与 Android 同设计:底部导航悬浮玻璃长椭圆(发现 / 音阁),发现页顶部分类玻璃胶囊条随页面滑动 1:1 联动;播放页、设置、频道详情为全屏页整体转场 | 音阁页头「设置」图标 → 设置页 |
| macOS | 窗口顶部工具栏内的分段切换(发现 / 音阁);详情用 `NavigationStack` 原生推入,底部常驻播放条 | 工具栏齿轮 / 菜单 `⌘,` → 标准 macOS 设置窗口 |

## 二、随机电台 / 情境电台

「下一首从哪来」由电台模块负责,「是否在台 / 自动续播」由播放门面统一持有。播完自动接下一首,最近 40 首去重。模式(随机 / 情境)在设置中切换。

| 平台 | 交互 |
|------|------|
| Android | 发现页右上角单个电台按钮:短按开台 / 换下一首,长按显示名称(运行中长按则停止),抓取中转圈。**情境模式图标随时段变为 日出 / 白日 / 日落 / 月亮**,随机模式为随机图标 |
| macOS | 工具栏电台按钮:点按开台,在台时点按 = 下一集,**右键菜单停止电台**;图标同样随随机 / 情境与时段变化(shuffle / sunrise / sun.max / sunset / moon.stars) |

## 技术特性

- **纯客户端**:零后端、零 API Key、无需登录,运行成本为 0
- **不接三方 SDK**:分享一律走系统能力(Android `ACTION_SEND` / macOS `ShareLink`·`NSSharingService` / 鸿蒙 ShareKit)
- **播客源**:Apple iTunes / Charts、fyyd.de、gpodder.net、RSS 直连 / OPML,全部公开免鉴权;播放回落发布方 RSS 的 enclosure 原始直链
- **持久化**:JSON 文件存于应用私有目录,**不引入数据库**

## 已知 / 未做

- **应用内升级**:需 CDN 托管分发,暂缓。
- **macOS 真实频谱**:受平台限制无法像 Android 那样抓取系统混音做 FFT,故 macOS 一律用程序化水墨动效替代。
- **鸿蒙真实频谱**:同样无对等手段 —— `SOURCE_TYPE_PLAYBACK_CAPTURE` 自 API 12 废弃,
  官方改用 native 的 `OH_AVScreenCapture`(需录屏授权),为一个封面动效索取录屏权限不成比例,
  故与 macOS 一致走程序化水墨动效,设置页不出现该开关。
- **macOS 后台更新**:无 WorkManager 式后台巡检,订阅更新通过「最新」手动刷新聚合。
